## Downer 2.1.0

### New
- **Sign in for videos that need it.** YouTube's "confirm you're not a bot" and age checks (and other sites that ask you to sign in) can now be passed using your browser's sign-in. It is **off by default**, and turning it on shows a consent screen that explains what happens first. Downer always tries without cookies, and only uses the chosen browser's cookies when a site says sign-in is required. Downer never saves, copies, uploads or logs cookies, and `yt-dlp` config files can't turn cookies on behind its back. For Safari, Settings shows whether Downer has Full Disk Access and has a button that opens the right pane. (#16, #15)
- **Best Compatibility.** One switch for MP4s that play in QuickTime, on iPhone and everywhere else. It fixes files that play sound but show no picture (AV1 or Opus inside an MP4). Most YouTube videos offer this only up to 1080p, and files are larger. The Information section explains it. (#14, #15)
- **MOV container**, next to MP4, MKV and WebM. MOV and WebM downloads are more robust too: WebM falls back to MKV when a site has nothing WebM can hold.
- **Extra yt-dlp arguments** in Settings → Advanced, limited to a list of common options such as `--limit-rate 2M` or `--embed-subs`. Anything else is refused, with the reason shown, so arguments can't break progress tracking, run commands or expose cookies. (#14)
- **deno, recommended for YouTube.** It can be installed from Settings and is passed to yt-dlp 2025.11.12 or newer automatically.
- **Update buttons** for yt-dlp, ffmpeg and deno, using Homebrew or self-update depending on how each was installed. They are disabled while a download runs, and tools Downer downloads itself are checked against their published checksum.
- **Downer updates itself.** It uses [Sparkle](https://sparkle-project.org). When it starts (and once a day, which you can turn off in Settings) Downer looks for a new version. A window appears on launch only if there is one, with **Install Update**, **Remind Me Later** and **Skip This Version**. Updates are signed and verified, Downer relaunches itself, and it waits for running downloads to finish first. **Check now** is in Settings.

### Improved
- **Clearer errors.** Failures now say what to do: turn on Sign-in, update yt-dlp, grant Safari Full Disk Access, allow the Keychain prompt, or that the video is unavailable. Messages are shorter and wrap instead of being cut off.
- Cancelling a link while it is being looked up now stops the look-up.
- Errors like "Unable to download webpage: HTTP Error 503" are now retried automatically, as other network hiccups already were.

### Updating from 2.0.x
Earlier versions can't update themselves, so download this DMG once. From here on, Downer updates itself.

SHA-256 is in `Downer-2.1.0.dmg.sha256`.
