## Downer 2.1.0

### New
- **Sign in for videos that need it.** YouTube's "confirm you're not a bot" and age checks can now be passed using your browser's sign-in. It is **off by default**. Turning it on shows a consent screen that explains exactly what happens first. Downer always tries without cookies, and only uses the chosen browser's cookies when a site says sign-in is required. Downer never saves, copies, uploads or logs cookies. For Safari, the consent screen shows whether Downer has Full Disk Access and has a button that opens the right Settings pane. (#16, #15)
- **Best Compatibility.** One switch for MP4s that play in QuickTime, on iPhone and everywhere else. It fixes files that play sound but show no picture (AV1 or Opus inside an MP4). Up to 1080p on YouTube; files are larger. (#14, #15)
- **MOV container**, next to MP4, MKV and WebM. MOV and WebM downloads are more robust too.
- **Extra yt-dlp arguments** in Settings → Advanced, limited to a list of common options, for example `--limit-rate 2M`. Anything else is refused, with the reason shown, so arguments can't break progress tracking, run commands or expose cookies. (#14)
- **deno, recommended for YouTube.** It can be installed from Settings and is passed to yt-dlp 2025.11.12 or newer automatically.
- **Update buttons** for yt-dlp, ffmpeg and deno, using Homebrew or self-update depending on how each was installed.
- **Automatic updates for Downer itself.** Downer now uses [Sparkle](https://sparkle-project.org). It checks GitHub for a new release when it starts and once a day (you can turn this off in Settings), and **Check now** is there too. Updates are signed and verified before they are installed, and Downer waits for running downloads to finish before it restarts.

### Improved
- **Clearer errors.** Failures now say what to do: turn on Sign-in, update yt-dlp, grant Safari Full Disk Access, allow the Keychain prompt, or that the video is unavailable. Messages are shorter and wrap instead of being cut off.
- Errors like "Unable to download webpage: HTTP Error 503" are now retried automatically, as other network hiccups already were.

### Updating from 2.0.x
Earlier versions can't update themselves, so download this DMG once. From here on, Downer updates itself.

SHA-256 is in `Downer-2.1.0.dmg.sha256`.
